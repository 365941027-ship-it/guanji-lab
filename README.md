# 观己实验室 · Self Insight Lab

> 理解自己，设计人生。东方智慧 × 哲学思考 × 数字工具的个人成长探索空间。

## 这是什么

根据「观己实验室」品牌方案搭建的静态网站，核心是一个完整的服务闭环：用户先通过测试看见自己，再通过人生设计获得方向，最后用成长轨迹持续记录并收到实时报告。页面不展示商业设计思路，专注产品理念与用户体验。

## 核心设计

- **结果不是定义，而是疗愈**：每份报告包含「核心特征」「内在冲突」「新的可能」「行动建议」「今日一问」「给此刻的你」，以及基于作答路径生成的个性化解读。
- **个性化评价**：`quiz.js` 会匹配你的具体答案组合，生成属于你的解读段落。
- **设计人生落地**：`design.js` 读取你的测试结果（localStorage），结合你输入的困惑、渴望与资源，生成三条 30 天原型实验路线和定制设计原则。
- **成长轨迹与实时报告**：`growth.js` 记录每日情绪、能量与文字，自动统计高频情绪、能量趋势、核心议题，并实时生成「你的成长报告」。
- **游戏化激励**：连续记录、星轨可视化、成就徽章与即时鼓励语，让记录本身变成一件被奖励的小事。
- **人生模拟**：`life-sim.js` 提供三个剧本（职业换轨 / 关系课题 / 自我探索），每次选择影响事业、关系、能量、自我四个维度，最终生成选择轨迹、维度变化、选择风格与「三年后的可能」。
- **具体化人生设计**：`design.js` 结合档案（MBTI、星座、八字）与上次模拟结果，输出具体分析、关键风险与对策、第一周清单、30 天检查点。
- **我的档案**：`profile.js` 支持输入生辰、时辰、出生地、MBTI、九型人格、八字四柱与星盘信息；星座由出生日期自动推算；所有信息仅存本机。
- **同频花园**：`garden.js` 根据测试与档案生成同频名片，支持话题留言（本机演示）；真正的用户匹配与私信需要后端支持，页面已如实标注。
- **板块深读**：每个测试结果页都包含所属板块的深度文章（荣格/福柯/东方哲学/塔罗象征延伸），把「一个板块说细说透」落到结果里。
- **轻量结果**：行动建议收敛为 1-2 条、不再说教；删除隐藏原型与一句提醒；每份结果附一封完整信件与「去记录」引导。
- **你的声音**：每道题支持「其他」自定义输入，你的原话会出现在结果里，成为个性化解读的一部分。
- **专属自察**：`custom-test.js` 读取档案、测试结果与成长记录，为每个用户动态生成 12 道专属题目与一封只写给 TA 的信。
- **深度结果**：结果页「核心特征 / 内在冲突 / 成长方向」三大板块均为 800 字以上长文，由结果数据、板块学理、塔罗象征与你的档案交叉生成。
- **登录与档案**：`login.html` 提供本地登录/注册（头像、昵称），登录状态显示在所有页面页头；档案页有登录引导。真实账号系统（手机号/邮箱、跨设备同步）为后续开发方向。
- **测试命名体系**：测试中心四大板块各 15 组、共 60 个测试名称，全部重新命名（如「你与世界相遇的姿态」「当工作开始抽干你」），与市面常见测试区分；22 组已可测，其余 38 组为「即将开放」内容路线图。
- **个性化人生模拟**：`life-sim.js` 根据档案、测试结果与成长记录动态生成「为你生成」的模拟剧本，同时保留自由剧本入口。
- **人生设计 2.0**：移除打卡式清单与检查点；三条思路各 800+ 字长文，不设任务；新增「个性天赋点」鼓励式成长板块。
- **多账户本地系统**：注册/登录/切换/退出，数据按账户命名空间隔离（`guan_data_<用户名>_*`）；接入真实后端账号即可升级为跨设备同步。
- **三十天陪伴**：`journey.js` 提供 30 天旅程框架——每周一封信、每日指引、情绪与记录，与专属自察、成长轨迹联动。
- **差异化题量**：测试题量按内容自然变化（22-28 题区间起步），不再全部统一，后续新增测试保持在 20-35 题。
- **专属自察去重**：动态题目聚焦固定测试未覆盖的「交叉维度」，避免重复；「你的声音」自定义输入会得到语义级回应，而非仅记录。
- **系统安全更新**：全站隐私明示横幅（数据仅存本机）、浮动求助按钮（心理援助热线/危机入口）、成长轨迹与档案的一键导出。
- **深度解读**：结果页自动生成约 3000 字专属解读（心理咨询师 × 塔罗 × 命理 × 职业规划四视角），完全免费；结合用户回答、档案、命盘与其他测试结果生成。
- 所有数据保存在浏览器 localStorage，不上传服务器。

## 如何运行

方式一（推荐）：启动脚本

```bash
./start-server.command
```

方式二：手动启动

```bash
cd "塔罗玄学 心灵疗愈"
python3 -m http.server 8777
```

然后浏览器打开 <http://127.0.0.1:8777>。

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，零依赖、无构建，可直接部署到任意静态托管。
- 测试引擎在 `assets/js/quiz.js`，题目与报告数据在 `assets/js/quiz-*.js`，新增测试只需加数据文件与页面。
- 视觉方向：深蓝黑底、金色点缀、东方留白、科技线条，贴合「哲学杂志 + 数字实验室」的品牌定位。
